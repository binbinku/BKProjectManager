# BK Project Manager v0.1.0

首个公开版本：为 macOS 和 Windows 11 打造的本地项目工作台。

## 下载

| 平台                            | 安装包                                 | 免安装 / 归档                          |
| ------------------------------- | -------------------------------------- | -------------------------------------- |
| macOS · Apple Silicon（M 系列） | `BKProjectManager-0.1.0-mac-arm64.dmg` | `BKProjectManager-0.1.0-mac-arm64.zip` |
| macOS · Intel                   | `BKProjectManager-0.1.0-mac-x64.dmg`   | `BKProjectManager-0.1.0-mac-x64.zip`   |
| Windows · x64                   | `BKProjectManager-0.1.0-win-x64.exe`   | `BKProjectManager-0.1.0-win-x64.zip`   |

macOS 用户打开 DMG 后，将应用拖入 Applications。Windows 用户可以运行 EXE 安装，或解压 ZIP 后运行 `BK Project Manager.exe`。首次启动请选择自己的工作空间。

## 功能

- 自动扫描工作空间，按一级目录分类，收纳 `Projects` 下的项目。
- 识别常见工程类型与 Git 标记，正确保留 Android 工程根目录。
- 搜索、收藏、最近打开，以及卡片 / 列表视图。
- 使用 Finder / 资源管理器、终端、VS Code、Cursor 或自定义编辑器打开项目。
- 亮色、暗色与跟随系统主题，偏好保存在本地。
- MIT 开源，提供中英文文档。

## 验证与签名

安装包分别在 GitHub Actions 的 macOS Apple Silicon、macOS Intel 和 Windows x64 环境构建；发布前运行扫描测试、配置持久化测试和已打包应用的桌面交互测试。Windows 构建使用 Windows Server runner，尚未完成 Windows 11 人工实机验证。

**此版本未配置开发者代码签名和 macOS 公证，系统可能显示来源或信任提示。** 应用目前使用默认 Electron 图标，暂不支持自动更新。附件 `SHA256SUMS.txt` 提供所有安装包及 ZIP 的 SHA-256 校验值。

## English

The first public release of BK Project Manager, a local project workspace for macOS and Windows 11.

- Discover projects from your existing directory structure, with category and `Projects` container support.
- Detect common project types and Git markers, including Android project roots.
- Search, favorites, recently opened projects, and card / list views.
- Open projects in your file manager, terminal, VS Code, Cursor, or a custom editor.
- Light, dark, and system themes with locally saved preferences.
- MIT licensed, with Chinese and English documentation.

**Downloads:** use `mac-arm64` for Apple Silicon, `mac-x64` for Intel Macs, or `win-x64` for Windows. DMG and EXE files are installers; ZIP files contain the application for manual extraction.

All three platforms build on native GitHub Actions runners and run scanning, persistence, and packaged desktop interaction tests before publication. The Windows runner uses Windows Server; manual Windows 11 testing remains pending.

**Developer code signing and macOS notarization are not configured.** Operating systems may display trust or origin prompts. This release uses the default Electron icon and has no automatic updater. Verify downloads using the attached `SHA256SUMS.txt`.
