# BK Project Manager v0.2.1

独立启动项目，把目录、代码和终端留在各自窗口；新增 GitHub 快捷入口与可按区域比例调节的毛玻璃。

## 更新内容

- **独立项目窗口**：灰色「启动项目」打开工作台，卡片随即变为绿色「运行中」。点击运行中的卡片或按钮会切回已有窗口；关闭项目窗口后恢复启动状态。同一项目不会重复打开。
- **保留工作现场**：返回项目列表或关闭管理窗口不会结束项目终端。每个项目的文件预览、终端与进程独立；关闭项目窗口会清理对应会话。
- **GitHub 仓库入口**：项目卡片、列表与工作台均可打开 GitHub 远程仓库。支持 HTTPS、SSH、Git worktree 与子模块，多仓库可通过原生菜单选择。地址中的凭证不会传给界面或浏览器。
- **三档毛玻璃**：关闭、中等、完整；透明度滑块支持 0–100%，拖动实时预览，结束后保存并同步到其他窗口。
- **区域比例**：完整模式下，主页侧栏 / 项目区按 **100% / 60%** 应用滑块数值；工作台目录 / 代码 / 终端按 **100% / 60% / 100%** 应用。例如滑块为 80%，工作台对应 80% / 48% / 80%。中等与关闭模式保持内容区实色。
- **更协调的工作台**：顶栏与目录共用侧栏材质，目录在顶栏下方独立滚动。GitHub 和外部编辑器按钮沿用项目卡片的圆角、边框、悬停及按下反馈；代码区与终端顶部保留不可见拖动区域。
- **卡片与工具栏**：直接用按钮启动项目，取消双击卡片进入；移除操作使用垃圾桶图标，新增 VS Code 快捷按钮。纵向悬浮工具叠在内容上，不为其预留侧边空白。
- **绘制修复**：侧栏背景与滚动内容分开合成，改善滚动残影；代码与终端在透明背景上保留 VS Code 高亮及 ANSI 真彩色。中英文 README 和示例截图同步更新。

结束需要保存的终端任务，退出旧版后再替换应用。已有工作空间、收藏与设置继续保留；旧配置默认使用完整毛玻璃及 60% 滑块数值，可在原生菜单的设置中调整。程序不会移动或删除项目文件，代码预览仍为只读。

全部安装包在本地 macOS 构建，**不使用 GitHub Actions**。Windows 安装包为跨平台构建，尚未在 Windows 11 实机验证。未配置开发者签名或 macOS 公证，暂不支持自动更新。附件 `SHA256SUMS.txt` 提供全部安装包的校验值。MIT 开源协议保持不变。

## English

v0.2.1 adds independent project windows, GitHub repository shortcuts and adjustable glass effects.

- Launch a project from its gray button; the card turns green while its window is running. Click a running card to focus the existing window. Closing it restores the launch state and cleans up its terminal session.
- Each project has an isolated file preview and terminal. Returning to the manager or closing the manager keeps project windows and their terminals running.
- Open GitHub repositories from cards, list rows and the workbench. HTTPS, SSH, worktrees and submodules are supported, with a native menu for multiple remotes. Credentials in clone URLs are never sent to the UI or browser.
- Choose Off, Medium or Full glass effects. The 0–100% slider previews while dragging and saves afterward. Full applies **100% / 60%** of the slider value to the manager sidebar / project area, and **100% / 60% / 100%** to the workbench tree / code / terminal. Medium and Off restore opaque content panes.
- The workbench header shares its sidebar material, with the tree scrolling below it. GitHub and external-editor controls use the same rounded buttons as cards. Code and terminal panels retain invisible window-drag areas at the top.
- Project cards now use explicit launch buttons, boxed icon controls, a VS Code shortcut and a trash icon for removal. Floating tools overlay the content. Double-clicking a card no longer opens a project.
- Separate backdrop and scrolling layers reduce sidebar artifacts. Transparent code and terminal panes preserve syntax and ANSI colors. Both READMEs and sample screenshots have been updated.

Choose `mac-arm64` for Apple Silicon, `mac-x64` for Intel Macs, or `win-x64` for Windows 11. Finish any terminal tasks and quit the old app before replacing it. Existing workspace and preferences are retained; older settings default to Full glass with a 60% slider value. Files are never moved or deleted by discovery, and code preview remains read-only.

macOS uses native materials and Windows 11 22H2 or newer uses Mica. Unsupported systems fall back to solid colors. The slider controls the theme tint; the native material itself retains its blur.

All installers are built locally on macOS, **without GitHub Actions**. Windows is cross-built and has not been runtime-tested on Windows 11. Developer signing, macOS notarization and automatic updates are not configured. Verify downloads with the attached `SHA256SUMS.txt`. Released under the MIT license.
