# BK Project Manager v0.2.0

从项目管理到项目工作台：浏览文件、查看代码、运行终端，并用七款内置配色打造自己的工作空间。

## 新功能

- **三栏工作台**：左侧资源目录、中间单文件只读预览、右侧真实交互终端；支持拖动调整面板。
- **代码预览**：VS Code Light+ / Dark+ 高亮、行号、UTF-8 / UTF-16 文本与常见图片，不显示多文件标签，不提供编辑保存。
- **真实终端**：在项目目录启动，支持 ANSI / 真彩色、滚动、Ctrl+C，以及原生菜单中的清空与重启。终端彩色输出不受外层无色环境变量影响。
- **七款内置配色**：默认、石墨、暖沙、森林、GitHub、Apple、MacBook Neo；全部适配亮色、暗色与跟随系统，在原生菜单的设置中切换并自动保存。
- **统一的工作台底色**：代码区、行号区和终端随主题协调，左侧目录保留同色系层次。只改颜色，布局与 VS Code 高亮色保持不变。
- **分类与项目管理**：自定义分类颜色与图标，创建分类和空项目；移除仅在本机隐藏，支持恢复。选择手动删除时先隐藏，再到 Finder / 资源管理器定位，由用户自行删除文件。
- **简洁的项目页面**：全部项目、收藏、最近打开和分类统一使用右下角纵向悬浮工具，提供视图、排序、扫描与新建；设置和工作空间管理位于原生菜单。
- **边到边布局**：代码区和终端上下延伸至窗口边缘；毛玻璃目录导航、Material Icon Theme 离线文件图标、1px 可拖动分界线，以及保留滚动能力的隐藏滚动条。
- **中英文说明**：更新项目管理页、工作台和七款主题的截图，默认中文 README，另附英文版。

## 下载与升级

| 平台                            | 安装包                                 | ZIP 归档                               |
| ------------------------------- | -------------------------------------- | -------------------------------------- |
| macOS · Apple Silicon（M 系列） | `BKProjectManager-0.2.0-mac-arm64.dmg` | `BKProjectManager-0.2.0-mac-arm64.zip` |
| macOS · Intel                   | `BKProjectManager-0.2.0-mac-x64.dmg`   | `BKProjectManager-0.2.0-mac-x64.zip`   |
| Windows 11 · x64                | `BKProjectManager-0.2.0-win-x64.exe`   | `BKProjectManager-0.2.0-win-x64.zip`   |

macOS 打开 DMG 后将应用拖入 Applications，替换旧版；Windows 运行 EXE 安装，或解压 ZIP 后启动应用。退出旧版前请结束需要保留的终端任务。已有工作空间和设置继续使用，旧配置自动使用默认配色。首次使用时选择工作空间即可。

## 构建与验证

全部安装包在本地 macOS 构建，**没有使用 GitHub Actions**。通过源码测试、打包后 macOS Apple Silicon 与 Intel（Rosetta 2）运行检查、工作台与终端检查、七主题亮暗切换和布局一致性检查，并验证 DMG / ZIP、图标、原生终端依赖及附件 SHA-256 校验值。

Windows x64 为 macOS 交叉构建，尚待 Windows 11 实机运行验证。分发包未配置开发者代码签名或 macOS 公证，系统可能显示来源或信任提示。暂不支持自动更新。附件 `SHA256SUMS.txt` 可用于核对下载文件。项目继续使用 MIT 协议开源。

## English

v0.2.0 brings a complete project workbench alongside project management.

- Browse the file tree, preview one read-only file with VS Code Light+ / Dark+ highlighting, and use a real terminal in the project directory. Resize the panels without file tabs or editing controls.
- Choose from seven palettes: Default, Graphite, Warm Sand, Forest, GitHub, Apple and MacBook Neo. All support light, dark and system appearance. The code viewer, gutter and terminal share the palette background; syntax colors and layout stay unchanged.
- Create categories and empty projects, customize category colors and icons, hide entries without deleting files, and restore them from Settings. Manual deletion first hides the entry and reveals its folder for you to delete yourself.
- All project views share vertical floating controls for view, sort, rescan and creation. Settings and workspace management live in the native menu.
- Full-height code and terminal panels, translucent navigation, bundled Material file icons, thin resizable dividers and hidden scrollbars with working scrolling.
- ANSI and true-color terminal output, Ctrl+C, clear and restart. Updated Chinese and English documentation with project-manager, workbench and theme screenshots.

Choose `mac-arm64` for Apple Silicon, `mac-x64` for Intel Macs, or `win-x64` for Windows 11. DMG and EXE files are installers; ZIP files are application archives. Quit the old application after finishing any terminal tasks before replacing it. Existing preferences remain available; older settings use the default palette.

All six packages are built locally on macOS, **without GitHub Actions**. Validation covers source tests, packaged Apple Silicon and Intel applications through Rosetta 2, workbench and terminal behavior, all palette/appearance combinations, unchanged layout, archive integrity, icons, native terminal dependencies and SHA-256 checksums. Windows is cross-built and still awaits Windows 11 runtime testing.

Developer code signing and macOS notarization are not configured, so systems may display trust prompts. Automatic updates are not implemented. Verify downloads with `SHA256SUMS.txt`. Open source under the MIT license.
