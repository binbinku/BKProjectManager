# BK Project Manager v0.1.1

本次更新将项目自己的 SVG 标志接入软件，并补齐各平台应用图标。

- 侧边栏、首次启动页面和页面图标统一使用现有标志。
- macOS 应用与 Dock 使用支持 Retina 的 ICNS / PNG 图标。
- Windows 程序、快捷方式、安装器和卸载器使用多尺寸 ICO 图标。
- 新增 `npm run icons:generate`，在 macOS 或 Windows 上从同一份 SVG 重新生成全部图标。
- 更新中英文 README 和软件截图。

## 下载

| 平台                            | 安装包                                 | 免安装 / 归档                          |
| ------------------------------- | -------------------------------------- | -------------------------------------- |
| macOS · Apple Silicon（M 系列） | `BKProjectManager-0.1.1-mac-arm64.dmg` | `BKProjectManager-0.1.1-mac-arm64.zip` |
| macOS · Intel                   | `BKProjectManager-0.1.1-mac-x64.dmg`   | `BKProjectManager-0.1.1-mac-x64.zip`   |
| Windows · x64                   | `BKProjectManager-0.1.1-win-x64.exe`   | `BKProjectManager-0.1.1-win-x64.zip`   |

macOS 用户打开 DMG 后将应用拖入 Applications。Windows 用户运行 EXE 安装，或解压 ZIP 后运行 `BK Project Manager.exe`。

## 构建与验证

六个安装包与归档均在本地 macOS 构建，没有使用 GitHub Actions。验证包括扫描与设置测试、Apple Silicon 应用交互测试、通过 Rosetta 2 运行的 Intel 应用交互测试、DMG / ZIP 完整性检查，以及 macOS 和 Windows 可执行文件中的图标资源检查。Windows x64 版本为交叉构建，尚待 Windows 11 实机运行验证。

**安装包尚未配置开发者代码签名与 macOS 公证，系统可能显示来源或信任提示。** 暂不支持自动更新。附件 `SHA256SUMS.txt` 提供全部安装包与 ZIP 的 SHA-256 校验值。v0.1.0 保留以供下载。

## English

This update brings the existing SVG logo into the application and all native application icons.

- Consistent branding in the sidebar, welcome screen and page icon.
- Retina ICNS / PNG icons for the macOS application and Dock.
- Multi-resolution ICO icons for the Windows application, shortcuts, installer and uninstaller.
- Run `npm run icons:generate` on macOS or Windows to regenerate all icons from the same SVG source.
- Updated Chinese and English documentation and screenshots.

Choose `mac-arm64` for Apple Silicon, `mac-x64` for Intel Macs, or `win-x64` for Windows. DMG and EXE files are installers; ZIP files contain the application for manual extraction.

All six packages are built locally on macOS, without GitHub Actions. Validation covers scanning and settings tests, desktop interactions on Apple Silicon and Intel through Rosetta 2, DMG / ZIP integrity, and icon resources in macOS and Windows executables. Windows packages are cross-built and still await Windows 11 runtime testing.

**Developer code signing and macOS notarization are not configured.** Systems may display trust or origin prompts. Automatic updates are not implemented. Verify downloads using the attached `SHA256SUMS.txt`. v0.1.0 remains available.
