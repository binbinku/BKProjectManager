# 项目目录说明

本文介绍 BK Project Manager 当前源码的目录组织、主要入口和生成文件，方便定位功能、调试和构建。下文的路径均相对于仓库根目录；软件中选择的「工作空间」是用户项目所在的目录，与源码仓库的目录结构是两回事。

## 目录总览

```text
BKProjectManager/
├── .vscode/                  # VS Code 调试与任务配置
│   ├── launch.json           # F5：开发调试、构建、打包和清理
│   ├── tasks.json            # Vite 后台服务、构建及打包任务
│   └── .user-data/           # 调试专用设置与 Electron 缓存（不提交）
├── electron/                 # Electron 主进程、预加载桥接与本地功能
├── src/                      # React + TypeScript 界面
│   └── generated/            # 自动生成的文件图标匹配表（不提交）
├── public/                   # Vite 静态资源目录
│   └── material-icon-theme/  # 自动生成的离线 SVG 图标（不提交）
├── build/                    # 应用、Dock、任务栏和安装器图标
├── scripts/                  # 开发、资源生成、测试、发布校验与清理脚本
├── tests/                    # Node.js 自动化测试
├── docs/                     # 项目文档
│   ├── 项目目录说明.md       # 当前目录说明
│   ├── 调试与构建配置说明.md # F5 配置、任务、使用场景及维护规则
│   ├── assets/               # SVG 标志、README 截图
│   └── 发布说明/             # 各版本中文发布说明
├── licenses/                 # 随应用分发的第三方许可
├── dist/                     # Vite 前端构建产物（不提交）
├── release/                  # Electron 应用目录与安装包（不提交）
├── artifacts/                # 桌面测试截图与调试产物（不提交）
├── node_modules/             # npm 依赖（不提交）
├── index.html                # 渲染页面入口与内容安全策略
├── package.json              # 版本、依赖、npm 命令与打包配置
├── package-lock.json         # npm 依赖版本锁定
├── AGENTS.md                 # 后续开发需要遵循的文档维护约定
├── tsconfig.json             # TypeScript 检查配置
├── vite.config.ts            # React 构建与本地开发服务配置
├── README.md                 # 中文说明，默认入口
├── README.en.md              # 英文说明
├── THIRD_PARTY_NOTICES.md     # 第三方资源与依赖的许可说明
└── LICENSE                   # 项目 MIT 许可证
```

## 主要入口与运行关系

应用入口由 [package.json](../package.json) 的 `main` 指向 [electron/main.cjs](../electron/main.cjs)。主进程负责创建项目管理窗口及独立工作台窗口，并处理菜单、设置、文件系统与终端。

界面通过 [index.html](../index.html) 加载 [src/main.tsx](../src/main.tsx)。项目管理页与工作台共用这一入口，通过窗口地址中的 `#project` 区分工作台，并按需加载工作台组件。

[electron/preload.cjs](../electron/preload.cjs) 将受限接口暴露为 `window.workspaceAPI`；对应的 TypeScript 定义位于 [src/types.ts](../src/types.ts)。界面不直接调用 Node.js 文件系统。项目文件和终端请求由主进程检查来源、窗口与会话，再交给相应模块执行。

增加本地功能时，通常需要同步修改主进程处理器、预加载接口、类型定义和调用它的界面组件。

## `electron/`：本地能力与应用生命周期

| 文件                                                             | 职责                                                                                                       |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [main.cjs](../electron/main.cjs)                                 | 应用启动、原生菜单、管理窗口与独立项目窗口、IPC 校验、外部软件与链接打开、外观同步及未保存内容的关闭保护。 |
| [preload.cjs](../electron/preload.cjs)                           | 通过 `contextBridge` 提供 `workspaceAPI`，封装 IPC 调用与事件订阅。                                        |
| [scanner.cjs](../electron/scanner.cjs)                           | 扫描工作空间，识别分类、`Projects` 容器、工程类型和 GitHub 远程仓库，生成扫描快照。                        |
| [workspace-management.cjs](../electron/workspace-management.cjs) | 校验跨平台名称、分类外观和目标路径，创建分类及空项目目录。                                                 |
| [visibility.cjs](../electron/visibility.cjs)                     | 保存分类与项目的隐藏状态，过滤展示快照；移除操作不删除项目文件。                                           |
| [store.cjs](../electron/store.cjs)                               | 加载、校验和保存设置，包括工作空间、收藏、最近打开、主题、毛玻璃及分类外观。                               |
| [workbench.cjs](../electron/workbench.cjs)                       | 管理单个项目的工作台会话与 PTY 终端，处理输入、尺寸、输出确认及进程释放。                                  |
| [project-files.cjs](../electron/project-files.cjs)               | 项目内路径校验、文件树读取、文本与图片预览，以及带版本冲突检查的 Markdown 保存。                           |
| [terminal-environment.cjs](../electron/terminal-environment.cjs) | 准备交互式终端环境，启用真彩色，去除宿主的禁色、CI 和调试注入变量。                                        |
| [github.cjs](../electron/github.cjs)                             | 读取本地 Git 配置，处理普通仓库、worktree 与子模块，将 GitHub 远程地址转换为不含凭证的网页地址。           |
| [app-icon.cjs](../electron/app-icon.cjs)                         | 获取 macOS 外部应用图标，供界面的外部打开按钮使用。                                                        |
| [palettes.json](../electron/palettes.json)                       | 七款内置配色的亮暗颜色值，供主进程与界面共同使用。                                                         |
| [category-options.json](../electron/category-options.json)       | 分类可选颜色、图标与名称匹配预设。                                                                         |

## 资源、生成文件与构建目录

| 路径                                | 来源与用途                                                                          | Git 管理 |
| ----------------------------------- | ----------------------------------------------------------------------------------- | -------- |
| [docs/assets/](assets/)             | README 截图与应用标志。`logo.svg` 是应用品牌图标的源文件。                          | 提交     |
| [build/](../build/)                 | 由 `npm run icons:generate` 从 `logo.svg` 生成 PNG、ICNS、ICO，供应用和安装器使用。 | 提交     |
| `public/material-icon-theme/`       | 从固定版本的 `material-icon-theme` npm 包复制的离线 SVG 及许可证。                  | 忽略     |
| `src/generated/material-icons.json` | 与离线 SVG 对应的文件、扩展名和目录匹配表。                                         | 忽略     |
| `dist/`                             | `npm run build` 生成的前端页面、脚本、样式和静态资源。                              | 忽略     |
| `release/`                          | electron-builder 生成的应用目录、DMG、EXE、ZIP 及打包辅助文件。                     | 忽略     |
| `artifacts/`                        | 桌面测试与截图脚本生成的截图和调试产物。                                            | 忽略     |
| `.vscode/.user-data/`               | VS Code 调试实例的独立设置与缓存。                                                  | 忽略     |

`npm run dev`、`npm run dev:renderer` 和 `npm run build` 会先生成文件树图标及匹配表。不要直接修改生成的 SVG 或匹配表；需要调整生成方式时，修改 [scripts/prepare-file-icons.mjs](../scripts/prepare-file-icons.mjs)。

`build/` 虽然名称中带有 build，但存放的是应用图标资源，不能作为临时构建目录删除。[scripts/clean.mjs](../scripts/clean.mjs) 仅允许清理 `dist/` 和 `release/`；也可分别执行 `npm run clean:dist` 与 `npm run clean:release`。

## `scripts/` 与 `tests/`：开发和验证

| 路径                                                                | 用途                                                                                                              |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [scripts/dev.mjs](../scripts/dev.mjs)                               | 创建 Vite 服务并启动 Electron，应用结束后关闭服务；对应 `npm run dev`。                                           |
| [scripts/prepare-native.cjs](../scripts/prepare-native.cjs)         | 修正 node-pty 的 macOS 原生辅助程序执行权限，用于开发、测试和打包准备。                                           |
| [scripts/prepare-file-icons.mjs](../scripts/prepare-file-icons.mjs) | 生成离线文件树图标与匹配表。                                                                                      |
| [scripts/generate-icons.mjs](../scripts/generate-icons.mjs)         | 从 SVG 标志重新生成应用图标。                                                                                     |
| [scripts/clean.mjs](../scripts/clean.mjs)                           | 按固定目录范围清理前端构建或本地打包产物。                                                                        |
| [scripts/native-menu.mjs](../scripts/native-menu.mjs)               | 桌面测试共用的原生菜单操作与项目窗口打开、关闭辅助函数。                                                          |
| `scripts/*-smoke.mjs`、[scripts/smoke.mjs](../scripts/smoke.mjs)    | 使用 Playwright 启动真实 Electron，验证管理页、分类、移除、配色、毛玻璃、GitHub、工作台、多窗口及 Markdown 交互。 |
| [scripts/readme-screenshots.mjs](../scripts/readme-screenshots.mjs) | 使用示例工作空间生成 README 截图；完整截图命令还会调用工作台测试脚本。                                            |
| [scripts/release-assets.mjs](../scripts/release-assets.mjs)         | 校验当前版本完整的六个跨平台发布文件，并生成 `SHA256SUMS.txt`；不会上传或发布 Release。                           |
| [tests/](../tests/)                                                 | 使用 Node.js 测试运行器验证扫描、创建、隐藏状态、设置、配色、GitHub 配置解析、文件访问与 Markdown 保存。          |

`npm test` 执行 `tests/*.test.cjs`。`npm run test:markdown` 等命令执行桌面交互测试，需要可用的桌面会话。`npm run test:windows` 中的 windows 指多个应用窗口，对应 `project-windows-smoke.mjs`，不代表自动在 Windows 系统中运行测试。

| [docs/发布说明/](发布说明/)                                                    | 已有版本的发布说明；以实际 GitHub Release 为准。                                |
| [licenses/](../licenses/)、[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) | 第三方完整许可和来源说明；打包时随应用分发。                                    |

正式设置由 Electron 的 `userData/settings.json` 保存，不在源码仓库中。设置 `BKPM_USER_DATA` 可以指定独立目录，VS Code 调试配置正是通过这个变量使用 `.vscode/.user-data/`。

F5 各入口的区别、任务菜单、调试结束方式和配置维护约定见[调试与构建配置说明](调试与构建配置说明.md)。新增配置时应同步更新该文档，具体约定记录在仓库根目录的 [AGENTS.md](../AGENTS.md)。

## 修改功能时从哪里开始

| 想修改的内容                                 | 优先查看                                                                                                               |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 项目卡片、收藏、最近打开或设置内容           | `src/main.tsx`；涉及保存时再看 `electron/main.cjs`、`electron/store.cjs`。                                             |
| 工作空间扫描、项目类型和 `Projects` 收纳规则 | `electron/scanner.cjs`、`tests/scanner.test.cjs`。                                                                     |
| 分类外观、新建分类与空项目                   | `src/ProjectManagerDialog.tsx`、`src/categories.tsx`、`electron/workspace-management.cjs`。                            |
| 从列表隐藏、恢复或手动删除入口               | `src/RemoveItemDialog.tsx`、`electron/visibility.cjs` 和主进程中的对应处理器。                                         |
| 工作台布局、目录宽度与拖动区域               | `src/ProjectWorkbench.tsx`、`src/workbench.css`。                                                                      |
| Markdown 阅读、图片或编辑                    | `src/MarkdownPreview.tsx`、`src/MarkdownEditor.tsx`、`src/MarkdownFile.tsx`；保存逻辑看 `electron/project-files.cjs`。 |
| 终端颜色、输入输出或进程释放                 | `src/ProjectTerminal.tsx`、`electron/workbench.cjs`、`electron/terminal-environment.cjs`。                             |
| 主题与毛玻璃                                 | `electron/palettes.json`、`src/palettes.ts`、`src/styles.css`；原生材质设置在 `electron/main.cjs`。                    |
| 应用图标或文件树图标                         | `docs/assets/logo.svg`、`scripts/generate-icons.mjs`，或 `scripts/prepare-file-icons.mjs`、`src/file-icons.ts`。       |
| F5 调试、打包或清理                          | `.vscode/`、`package.json`、`scripts/clean.mjs`。                                                                      |

开发、打包和测试命令的完整用法见[中文 README](../README.md#development)。目录或模块调整后，请同步更新本文中的路径与职责说明。
