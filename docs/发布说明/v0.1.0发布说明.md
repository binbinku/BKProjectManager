# BK Project Manager v0.1.0 发布说明

首个公开版本：为 macOS 和 Windows 11 打造的本地项目工作台。

## 下载

| 平台                            | 安装包                                 | 免安装 / 归档                          |
| ------------------------------- | -------------------------------------- | -------------------------------------- |
| macOS · Apple Silicon（M 系列） | `BKProjectManager-0.1.0-mac-arm64.dmg` | `BKProjectManager-0.1.0-mac-arm64.zip` |
| macOS · Intel                   | `BKProjectManager-0.1.0-mac-x64.dmg`   | `BKProjectManager-0.1.0-mac-x64.zip`   |
| Windows · x64                   | `BKProjectManager-0.1.0-win-x64.exe`   | `BKProjectManager-0.1.0-win-x64.zip`   |

macOS 用户打开 DMG 后，将应用拖入 Applications。Windows 用户可以运行 EXE 安装，或解压 ZIP 后运行 `BK Project Manager.exe`。首次启动请选择自己的工作空间。

## 功能

- 自动扫描工作空间，按一级目录分类，收纳 `Projects` 下的项目。
- 识别常见工程类型与 Git 标记，正确保留 Android 工程根目录。
- 搜索、收藏、最近打开，以及卡片 / 列表视图。
- 使用 Finder / 资源管理器、终端、VS Code、Cursor 或自定义编辑器打开项目。
- 亮色、暗色与跟随系统主题，偏好保存在本地。
- MIT 开源，提供中英文文档。

## 验证与签名

所有安装包均在本地 macOS 构建，本次发布不使用 GitHub Actions。macOS Apple Silicon 应用在本机运行桌面交互测试，Intel 应用通过 Rosetta 2 测试；同时运行扫描和配置持久化测试。Windows x64 安装包为交叉构建，尚未完成 Windows 11 实机运行验证。

**此版本未配置开发者代码签名和 macOS 公证，系统可能显示来源或信任提示。** 应用目前使用默认 Electron 图标，暂不支持自动更新。附件 `SHA256SUMS.txt` 提供所有安装包及 ZIP 的 SHA-256 校验值。
